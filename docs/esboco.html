// 01 — Isso é pra você?

Você tem dados. Falta transformá-los em decisão.

→ previsão de demanda

Compras guiadas por previsão semanal, com menos ruptura e menos capital parado.

"Cada área tem uma planilha diferente."

→ engenharia + BI

Uma fonte única de verdade e um painel que o time realmente abre.

"Não sabemos por que os clientes saem."

→ modelo de churn

Lista semanal de clientes em risco com o motivo provável de cada um.
