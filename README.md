# Site Cientista de Dados — Felipe Fuck

Site de alta conversão para consultoria e projetos freelance de ciência de dados.
Conceito: **"Do ruído ao sinal"** — hero 3D (Three.js) em que partículas vão de ruído → clusters → modelo conforme o scroll.

## Arquivos

- [`PLANO.md`](PLANO.md) — plano completo: posicionamento, arquitetura de informação, direção de arte, 3D/motion, CRO, stack, SEO, checklist de conteúdo e roadmap.
- [`esboco.html`](esboco.html) — esboço navegável (wireframe mid-fi) com notas de UX e protótipo 3D funcional.

## Rodar localmente

Abra `esboco.html` no navegador (precisa de internet para Three.js e fontes), ou:

```bash
python3 -m http.server 8000
# http://localhost:8000/esboco.html
```
